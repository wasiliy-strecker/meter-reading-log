# Create ZählerstandLog Flutter app

- Added the standalone Android-first Flutter application with meter management,
  local photo capture, on-device OCR candidate confirmation, exact reading
  history, correction revisions, and optional local reminders.
- Added original-photo, manifest, and PDF SHA-256 integrity records together
  with individual/history PDF reports and local PDF verification.
- Added password-encrypted full backup and restore for meters, readings,
  revisions, photos, reports, and reminder settings.
- Added custom meter branding, German UI, focused tests, privacy documentation,
  MPL-2.0 licensing, and third-party font notices.
- Added a conditional in-memory web shell for fast UI checks while keeping all
  private persistence and device integrations in native implementations.
