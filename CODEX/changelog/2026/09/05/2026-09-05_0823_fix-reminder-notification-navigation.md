# Navigation aus Erinnerungen korrigiert

- Die interne Benachrichtigungsadresse wird nicht mehr als Flutter-Webroute interpretiert.
- Das Antippen einer Zählererinnerung öffnet weiterhin über die vorhandene Zähler-ID den zugehörigen Zähler.
- Die manuell verwaltete Benachrichtigungsnavigation ist im Android-Manifest ausdrücklich von Flutters automatischem Deep-Linking getrennt.
