# Zählerartspezifische Erinnerungssymbole

- Übergibt die stabile Zählerart an den nativen Android-Erinnerungsdienst.
- Zeigt in Erinnerungen passende Symbole für Strom, Photovoltaik, Gas, Wasser, Kaltwasser, Warmwasser, Wärme, Heizkostenverteiler, Öl und sonstige Zähler.
- Behält die Kompatibilität mit bereits gespeicherten Erinnerungen bei.

## Prüfung

- `dart format lib test`
- `flutter analyze`
- `flutter test`
- `flutter build apk --debug`
