# Farbige Symbole in Erinnerungen

- Zeigt in Android-Erinnerungen ein rundes, farbiges Symbol passend zur Zählerart.
- Verwendet dieselben Farben wie das Dashboard, darunter Rot für Gas und Dunkelorange für Strom.
- Setzt zusätzlich die Akzentfarbe der Benachrichtigung passend zur Zählerart.
- Belässt das kleine Android-Statusleistensymbol entsprechend der Systemvorgaben einfarbig.

## Prüfung

- `dart format lib test`
- `flutter analyze`
- `flutter test`
- `flutter build apk --debug`
